# CODEGUARD — COMPLETE FRONTEND DEVELOPMENT PROMPT

## Project Title

**CodeGuard — A Behavior-Aware Secure Online Judge Using Windows OS-Level Isolation**

Build a complete, polished, functional frontend for CodeGuard, an Operating Systems academic project.

CodeGuard is an online compiler and behavior-monitoring platform designed to demonstrate how student programs can be executed in a controlled Windows environment while monitoring resource usage, process activity, filesystem events, and suspicious runtime behavior.

The application must combine three experiences:

1. A professional online compiler and coding workspace.
2. An interactive execution and security simulation.
3. A comprehensive administration and security-monitoring dashboard.

I will develop the backend separately using Python, FastAPI, and PostgreSQL.

**Your task is frontend development only. Do not build the backend, database, compiler, or Windows execution engine.**

## Execution timeline

```text
CODE SUBMITTED
      ↓
COMPILATION
      ↓
PROCESS CREATED
      ↓
RESOURCE CONTROLS APPLIED
      ↓
PROGRAM EXECUTION
      ↓
BEHAVIOR MONITORING
      ↓

      ↓
```

## Scenario details

### Normal Program

Show a normal execution lifecycle, test evaluation, and a successful result.

### Infinite Loop

Show elapsed execution time increasing until the configured deadline is reached.

The simulated result should be:

`TIME LIMIT EXCEEDED`

### Memory-Heavy Program

Show memory consumption approaching the scenario's configured limit and display a limit event if defined by the scenario.

### Excessive Process Creation

Show child-process events and an active process count approaching the configured limit.

### Restricted File Access Attempt

Show an attempted access to a protected resource.

Clearly label whether the event was:
- Simulated.
- Observed.
- Actually blocked by the backend.

### Possible Hardcoded Solution

Show visible tests passing and generated tests exposing a possible issue.

Label the result as a review signal, not proof of cheating.

### Suspicious Event Sequence

Show a chronological sequence and highlight the configured rule that matches it.

- `LIVE BACKEND`
- `SIMULATION`

Simulation data must be visually distinguishable from actual backend data.

Use labels such as `SIMULATED EVENT` and `DEMO DATA`.
